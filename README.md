# network-traffic-analysis
## Overview
This repository documents network traffic analysis exercises performed using Wireshark.The focus is on understanding network communications, investigating suspicious activity, and analysing packet captures (PCAPs).

## Topics Covered
* Packet Capture Analysis
* DNS Investigation
* HTTP Traffic Analysis
* TCP/IP Investigation
* Protocol Analysis
* Suspicious Traffic Identification

## Tools Used
* Wireshark

## Skills Demonstrated
* Packet Analysis
* Network Security
* Traffic Investigation
* Protocol Understanding
* Incident Analysis

## Key Learning Outcomes
* Understanding network communication
* Analysing packet captures
* Identifying suspicious traffic patterns
* Investigating DNS and HTTP activity
* Developing troubleshooting skills
